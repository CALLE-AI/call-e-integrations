# Earlier Dual-Skill Installation Guide

The earlier separate API and MCP entries were merged during testing. The current
canonical standalone workflow is [`calle` 2.0.1](calle.md), which prefers MCP
and supports API Key access under its interface selection rules. Users retaining
the legacy CLI workflow can install [`calle-cli`](skills-sh-skill.md).

This page preserves earlier links. Historical verification records retain their
original identities, versions, hashes and evidence limits.
