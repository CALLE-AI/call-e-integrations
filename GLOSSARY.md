# CALL-E Integration Identities

These terms distinguish the standalone CALL-E Skill identities discussed in
the migration plan.

## Language

**Standalone calle**:
The canonical identity of the current standalone CALL-E Skill.
_Avoid_: Unqualified "calle" when the standalone Skill, CLI executable and
plugin identities could be confused.

**callev2**:
The retired testing identity that preceded the canonical standalone CALL-E
Skill.
_Avoid_: Using "callev2" as the canonical release name.

**calle-cli**:
The compatibility Skill identity for users retaining the legacy CALL-E workflow.
_Avoid_: Using "calle-cli" as the name of the CLI executable.
